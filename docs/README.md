# X-Plane 12 Aircraft Tools: User Guide

X-Plane 12 Aircraft Tools is a Blender add-on for making X-Plane 12 aircraft and cockpits. It is an unofficial fork of
XPlane2Blender with its own panels, so even if you know XPlane2Blender, start with [Getting Started](getting-started.md).

| Page | What it covers |
|---|---|
| [Getting Started](getting-started.md) | Installing, where the add-on's panels are, and your first export |
| [Cockpit Controls](cockpit-controls.md) | Making parts clickable, animating them, showing and hiding them, backlighting, attachment points |
| [Lights](lights.md) | Library lights, spills and glow sprites, and seeing them as X-Plane draws them |
| [Materials And Screens](materials-and-screens.md) | Transparency, shadows, the 2D panel and avionics screens |
| [Files And Export](files-and-export.md) | Export files, their textures and settings, exporting work in progress |
| [Importing](importing.md) | Bringing in a whole aircraft (.acf) or single OBJs |
| [Working Faster](working-faster.md) | The pie menu, Shift+A, find and replace, tables and CSV, the X-Plane workspace |
| [Settings Reference](reference.md) | Every setting, button and menu, with its tooltip |
| [Technical Notes](technical-notes.md) | How lights, animations and imports are converted, for when the guides are not enough |

The pictures are taken of a small demo cockpit in Blender 5.2. In other Blender versions the panels look the same,
Blender's own parts of the window may differ a little.

## Keeping These Pages Up To Date

The pages are checked with the add-on's tests, so they cannot quietly fall behind it: a screenshot of a panel that now
draws something else, a button the pages name that no longer exists, or a new panel or button that no page mentions
fails the tests. [Maintaining The Docs](maintaining-the-docs.md) explains how to update them.
